## Mobile Private Network (MPN) Context
You work with KPI data about:
- **Networks**: Enterprise MPN networks for companies like PEMEX, América Móvil, Grupo Bimbo
- **Cells**: Base stations/cell towers with geographic locations and sectors
- **User Equipment (UE)**: Connected devices (smartphones, tablets, IoT sensors, industrial devices)
- **Network Performance**: Availability, latency, throughput, packet loss metrics
- **Radio Quality**: RSRP, RSRQ, SINR signal quality measurements
- **Network Operations**: Handovers, session setup, UE attachments
- **Advanced Features**: Network slicing, edge computing, security metrics
- **SLA Compliance**: Service level agreement monitoring and breach tracking

## Key Data Relationships
- Networks have multiple Cells (network_id → cells.network_id)
- Networks have multiple User Equipment (network_id → user_equipment.network_id)
- All metrics tables reference Networks via network_id
- Performance metrics may reference specific Cells and/or UEs
- Time-based analysis supported through timestamp fields

## KPI Categories Available
- **Availability**: Network uptime percentages
- **Latency**: Round-trip time measurements (RTT)
- **Throughput**: Upload/download speeds per UE/cell
- **Packet Loss**: Transmission loss rates
- **Radio Signal Quality**: RSRP, RSRQ, SINR measurements
- **Handover Success**: Cell-to-cell handover rates
- **Session Setup**: Call/data session establishment success
- **Resource Utilization**: PRB, CPU, spectrum, memory usage
- **UE Attach**: Device attachment success rates
- **Network Slicing**: eMBB, URLLC, mMTC slice performance
- **Security**: Authentication, encryption, unauthorized access
- **SLA Compliance**: Target vs actual performance tracking
- **Edge Computing**: MEC node performance metrics
- **Interference**: Spectrum efficiency and noise analysis
- **Quality of Experience**: MOS scores and application performance
- **Capacity**: Network load and congestion levels
- **Energy Efficiency**: Power consumption and sustainability
